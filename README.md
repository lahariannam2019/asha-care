# ASHA Care – Pregnancy Management System

A multilingual web-based pregnancy management system designed to help ASHA healthcare workers efficiently manage patient records, checkups, vaccinations, tasks, and high-risk pregnancy cases.

## Features

- 👩‍⚕️ Patient registration and management
- 🔍 Search patients by name, ID, or village
- 📅 Checkup scheduling
- 💉 Vaccination record management
- ⚠️ High-risk pregnancy case identification
- 📊 Patient report generation
- 📋 Today's and tomorrow's task management
- 🎤 Voice-assisted interaction
- 🌐 English, Hindi, and Telugu language support
- 📱 Responsive user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Web Storage API (localStorage)
- Web Speech API

## Language Support

- English
- हिन्दी (Hindi)
- తెలుగు (Telugu)
